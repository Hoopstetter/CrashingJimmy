# Crash'n Jimmy v221-A290

Category 6 — Scoring, progression & game structure.

A290 adds a derived PACE CONTROL TOUR across Big Bear, Orange County and SoCal. It uses the existing sport-specific A282 Pace Control banks and adds no new save field or score points.

The tour rank is the lowest Pace Control tier across the three disciplines:
- OPEN
- ALL-SPORT REPEATABLE
- ALL-SPORT PACE CONTROL
- ALL-SPORT DIALED PACE
- ALL-SPORT PACE COMMAND

This prevents one-course farming: Jimmy only advances the cross-sport rank when the weakest discipline reaches the next Pace Control tier. The Scoreboard and Full Run Stats now show the all-sport state, and Results reports a rank-up when the balanced tour advances.
